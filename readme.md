# Evil Wizard RPG 🧙‍♂️⚔️

A text-based, turn-based Role Playing Game (RPG) built in Python. This project demonstrates core Object-Oriented Programming (OOP) concepts such as classes, inheritance, and method overriding.

## 📝 About the Project

In this game, the player chooses a character class and battles against a powerful boss, the **Evil Wizard**. The combat system runs in a continuous loop until either the player or the wizard's health drops to zero.

This project was developed as an assignment for **Coding Temple** to practice Python fundamentals and OOP structuring.

## ✨ Features

- **Multiple Character Classes**: Choose between a Warrior, Mage, Archer, or Paladin, each with their own unique stats (Health, Attack Power, Special Attack, and Heal amount).
- **Dynamic Combat**:
  - Basic attacks deal randomized damage within a specific range for unpredictable combat.
  - Special abilities deal heavy fixed damage.
- **Healing System**: Characters can heal themselves during battle, but they cannot heal past their original maximum health.
- **Boss Mechanics**: The Evil Wizard regenerates health every turn before striking back.

## 🚀 How to Run

1. Make sure you have Python 3 installed on your machine.
2. Open your terminal and navigate to the project directory.
3. Run the script using the following command:

```bash
python3 evilWizard.py
```
